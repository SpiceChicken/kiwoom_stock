[핵심 물리 엔진 도감 (The 6 Physical Forces)]
본 시스템은 주가 흐름을 동역학으로 해석합니다. 첨부된 데이터의 변수들은 다음을 의미합니다.
* 가속도(Net Force): Thrust + Gravity + Drag + Magnetic + Jerk 의 최종 합력. 뇌동매매를 차단하는 진입의 최종 관문.
* 속도(Velocity): 이전 속도 + Net Force + Impulse 로 계산된 주가의 현재 모멘텀 상태.
1. 추진력(Thrust): 체결강도 100% 초과분과 거래량(Volume Ratio)을 곱한 기본 상승 엔진.
2. 중력(Gravity): 평균가(VWAP) 괴리에 따른 탄성 저항력. 과열 매수와 가짜 반등(Dead cat bounce)을 차단.
3. 항력(Drag): RSI 기반 마찰열. 주가 급등 시 차익실현 매물 저항.
4. 자기력(Magnetic): 매도 호가창에 물량이 쌓여있을 때 발생하는 위쪽으로의 진공 흡입력.
5. 져크(Jerk): 가속도의 미분값. 수급의 가속/감속을 파악하여 폭포수 붕괴 전 조기 탈출(Bail-out)하는 핵심 척도.
6. 충격량(Impulse): 1억 원 이상 대량 틱 체결대금. (방향성 검증용)

[시스템 평가 및 분석 가이드라인 (절대 준수)]
1. **객관적 성과 평가**: 표면적인 승률(%)에만 집착하지 말고, 총 누적 수익률(PnL)과 매매 횟수를 바탕으로 당일 시장의 난이도 대비 시스템의 방어력과 공격력을 종합 평가하십시오.
2. **동역학(Kinematics) 기반 타점 해석**: 특정 하드코딩된 로직이 아닌 '물리적 힘(Thrust, Gravity, Drag, Impulse, Jerk)'의 상호작용 관점에서 진입을 평가하십시오. 
   - *예외 인지:* 최종 합력(Net Force)이 마이너스(< 0)이더라도, 거대한 충격량(Impulse)과 가속도(Jerk)가 동반된 타점은 시스템 오류가 아니라 '압도적인 자본으로 저항을 뚫어낸 유효한 돌파 전술'로 해석해야 합니다.
3. **리스크 관리 능력 (Exit Logic)**: 잦은 손절(Stop Loss)이 발생했더라도 그 손실폭이 시스템 통제 하에 좁게(-1% 내외) 방어되었는지, 반대로 수익은 끝까지 추적하여 보존(Trailing Stop, Bail-out)했는지 시스템의 '손익비 관리 능력'을 평가하십시오.
4. **외부 노이즈 및 데이터 이상치(Anomaly) 인지**: 비정상적인 괴리율(-100% 등)이나 0원 청산과 같은 극단적 오류 데이터는 엔진의 논리적 결함이 아니라, '거래소 VI(단일가 매매) 발동 등 외부 API 데이터 오염'으로 인한 노이즈로 인지하고 분리하여 평가하십시오.
